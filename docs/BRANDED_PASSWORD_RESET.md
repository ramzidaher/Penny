# Branded Password Reset Email

Password reset emails are sent via **Resend** from your own domain (e.g. `noreply@pennyfinance.app`) with Penny branding. This improves deliverability (less likely to hit spam) and looks professional.

## How it works

1. User taps "Forgot Password?" on the login screen and enters their email.
2. The app calls the Cloud Function `requestPasswordReset`.
3. The function generates a Firebase reset link and sends a **branded HTML email** through Resend (from your domain).
4. If Resend is not configured, the app falls back to Firebase’s default email (from `*.firebaseapp.com`).

## Setup (one-time)

### 1. Resend account and domain

1. Sign up at [resend.com](https://resend.com).
2. Add and verify your domain (e.g. `pennyfinance.app`) in the Resend dashboard. This involves adding the DNS records they provide (SPF, DKIM). Verified domain = better deliverability and no “via firebaseapp.com”.
3. Create an API key in Resend and copy it.

### 2. Environment variables for the Cloud Function

Set these for the `requestPasswordReset` function so it can send email:

| Variable | Required | Example | Description |
|----------|----------|---------|-------------|
| `RESEND_API_KEY` | Yes | `re_...` | Your Resend API key. |
| `PASSWORD_RESET_FROM` | No | `Penny <noreply@pennyfinance.app>` | Sender address (must be from a verified domain). Default: `Penny <noreply@pennyfinance.app>`. |
| `PENNY_LOGO_URL` | No | `https://pennyfinance.app/logo.png` | Public URL for the logo in the email. Default: `https://pennyfinance.app/logo.png`. |

**Where to set them**

- **Deployed (production):**  
  Google Cloud Console → Cloud Functions → select `requestPasswordReset` → Edit → **Runtime, build, connections and security** → Environment variables. Add `RESEND_API_KEY`, and optionally `PASSWORD_RESET_FROM` and `PENNY_LOGO_URL`.

- **Local emulator:**  
  In `functions/`, create a `.env` file (do not commit it) with:
  ```
  RESEND_API_KEY=re_xxxx
  PASSWORD_RESET_FROM=Penny <noreply@pennyfinance.app>
  PENNY_LOGO_URL=https://pennyfinance.app/logo.png
  ```
  Load this in your emulator/config if your setup supports `.env` for local runs.

### 3. Logo and link

- Host your Penny logo at a public URL (e.g. `https://pennyfinance.app/logo.png`) and set `PENNY_LOGO_URL` if you use a different URL.
- The reset link in the email is generated by Firebase; after the user sets a new password they are taken to the Firebase completion page. You can later add a custom action URL in Firebase if you want a redirect back to your app.

## After setup

- All “Forgot Password?” requests use the branded flow when `RESEND_API_KEY` is set.
- If the function is not configured (e.g. missing `RESEND_API_KEY`), the app falls back to Firebase’s default password reset email so users can still reset their password.

## Security

- Rate limiting: 3 reset requests per IP per 15 minutes.
- We do not reveal whether an email is registered; the same success message is shown either way.
- Email is validated and escaped in the HTML template.
