## Reviewer Access Notes

### Demo access
- Configure demo reviewers with `EXPO_PUBLIC_DEMO_EMAILS` (comma-separated).
- Demo users see a "Continue demo" option on the paywall to bypass subscription gating.

### Suggested reviewer test flow
- Sign in with the provided reviewer credentials.
- Navigate to AI and request guidance (ensure disclaimer is visible).
- Open Settings to manage subscriptions and restore purchases.
- Verify account deletion option is available in Settings.
